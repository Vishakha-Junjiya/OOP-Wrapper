# Python OOP Project: Employee Management System

## 📌 Project Description

The Employee Management System is a Python-based project developed using Object-Oriented Programming (OOP) concepts. It manages the details of persons, employees, managers, and developers through a menu-driven program.

## 🎯 Project Objectives

* To understand and implement Python OOP concepts.
* To manage person and employee details.
* To demonstrate inheritance, encapsulation, and method overriding.
* To use getter and setter methods for data access.
* To check class relationships using `issubclass()`.

## 🛠️ Technologies Used

* **Programming Language:** Python
* **Concepts:** Object-Oriented Programming (OOP)

## ✨ Features

1. Create a Person
2. Create an Employee
3. Create a Manager
4. Create a Developer
5. Display Details
6. Exit the System

## 📚 OOP Concepts Used

* **Class and Object:** Used to represent persons, employees, managers, and developers.
* **Inheritance:** The Employee class inherits from Person. Manager and Developer inherit from Employee.
* **Encapsulation:** Employee ID and Salary are stored as private attributes.
* **Constructor (`__init__`):** Initializes object attributes.
* **`super()` Method:** Calls the parent class constructor and methods.
* **Method Overriding:** Manager and Developer provide their own display methods.
* **Getter and Setter Methods:** Used to access and modify private attributes.
* **`issubclass()`:** Checks the inheritance relationship between classes.
